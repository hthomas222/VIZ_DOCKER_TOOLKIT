# VIZ_DOCKER CLI Dashboard

Viz_Docker CLI is a Python tool that allows users to run Docker commands simply by typing a number. The project utilizes `Rich` to provide colorized terminal output.

## Features

- **Colored Output**: Utilizes `Rich` for enhanced visual styling in the terminal.
- **Docker Containers Overview**: Displays clear, formatted container information.

## Prerequisites

- **Python 3.7+**
- **Docker** installed and running on your system.
- Permission to run `docker` commands without `sudo` (or run the script as root/sudo).
